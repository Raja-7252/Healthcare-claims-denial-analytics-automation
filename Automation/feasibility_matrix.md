# RPA Feasibility Assessment  
## Healthcare Claims Denial Analytics & Automation  
## Author: Raja Kalyanapu  

---

## 🎯 Purpose  
To evaluate which steps in the claims workflow are suitable for automation using UiPath based on:

- Volume  
- Rule-based logic  
- System stability  
- Input/output structure  
- Exception rate  

---

# 🧩 Feasibility Scoring Criteria  

| Criteria | Description |
|---------|-------------|
| Volume | Frequency of transactions |
| Rule-based | Predictability of decision logic |
| System Stability | Consistency of applications |
| Input Structure | Structured vs unstructured data |
| Exceptions | Human intervention frequency |

Scoring:  
**High = 3, Medium = 2, Low = 1**

---

---

# 🔎 Summary  
- **High Automation Potential:**  
  - Eligibility verification  
  - Claim submission  
  - Denial categorization  
  - Billing system data entry  

- **Medium Potential:**  
  - Document completeness  
  - Appeal creation  

- **Low–Medium Potential:**  
  - Coding validation (requires clinical judgment)

---

# ✔ Recommendation  
Start with **Eligibility Verification Bot** and **Denial Categorization Bot** — fastest ROI.

These automations deliver:
- High time savings  
- Low complexity  
- Quick deployment  
- High financial impact  
- Strong stakeholder value
