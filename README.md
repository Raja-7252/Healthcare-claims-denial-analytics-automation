# Healthcare Claims Denial Analytics & Automation  
*A complete end-to-end Business Analyst project showcasing healthcare domain knowledge, data analysis, process mapping, and RPA feasibility.*


## 🏥 Project Overview  
Healthcare providers lose millions annually due to claim denials. This project analyzes denial root causes, identifies inefficiencies in the claims workflow, and recommends process improvements + automation opportunities using RPA (UiPath).

This project demonstrates skills across:
- Business Analysis (BRD, FRD, User Stories, Acceptance Criteria)
- Healthcare Workflow Understanding (Claims → Denials → Rework)
- SQL Data Analysis (denial patterns, root causes)
- Power BI Dashboard Design
- Process Mapping (AS-IS & TO-BE flows)
- RPA Feasibility Assessment (PDD + ROI)


## 🎯 Problem Statement  
Healthcare organizations face **high denial rates (10–25%)**, leading to:
- lost revenue  
- manual rework  
- administrative burden  
- delayed reimbursements  

This project identifies root causes and proposes automation + process redesign to reduce denials and improve financial performance.
